## About the repository

- `index.html` is the portfolio homepage.
- `assets/` contains the website styling and JavaScript.
- `projects/` contains the case studies, technical documentation and project evidence.
- `CCNA Quiz/` contains the interactive quiz and its supporting project files.

The portfolio is a static website hosted on GitHub Pages. The cybersecurity and infrastructure projects are documented test labs, not production deployments. Alert Nepal runs locally; its public folder contains documentation and graphics, not private API credentials or the complete application source code.

Older website experiments and retired support files are kept in the [project archive](https://github.com/lcashish1/purushottam-lamichhane/tree/main/legacy-website), separate from this portfolio.
