Project overview

Azure honeypot and security event visualisation.

What I implemented

  • Deployed an Azure Windows VM as a controlled honeypot and collected failed-login events.
  • Used Log Analytics, Azure Monitor Agent and KQL to query security events.
  • Added GeoIP watchlist enrichment and displayed attack activity in Microsoft Sentinel Workbooks.

Outcome & learning

A visual SOC learning project demonstrating how security logs become investigative data.
