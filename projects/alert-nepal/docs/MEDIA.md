# Visual evidence and media use

This project folder includes **original vector illustrations**:

- [Cover graphic](../assets/cover.svg)
- [Workflow diagram](../assets/architecture.svg)
- [Illustrative news card](../assets/card-preview.svg)

These are portfolio visuals, **not evidence of a specific published news post**.

The public [Alert Nepal Facebook Page](https://www.facebook.com/people/Alert-Nepal/61595921800739/) remains the reference for actual published posts. When adding screenshots from the Page in the future:

1. Verify that the post was published and that the image belongs to the Page.
2. Add the screenshot only if appropriate to reproduce in a personal portfolio.
3. Credit the original photographer/news publisher where applicable.
4. Avoid including access tokens, personal account information, or private messages.
5. Do not imply that AI-generated pictures document real events.

To extend this project with genuine publication screenshots, add suitably redacted PNG/WebP images to the `assets/` directory and update README image links.
