Project overview

Cloud security lab using segmentation, threat monitoring and response automation.

What I implemented

  • Designed an Azure virtual network with dedicated subnets and Network Security Groups for controlled access.
  • Configured Microsoft Sentinel and KQL-based detection for simulated Linux SSH brute-force activity.
  • Documented a Logic Apps playbook for reacting to Sentinel incidents and creating network deny rules.

Outcome & learning

This lab demonstrates connecting identity, network controls, monitoring and incident response into an Azure security architecture.
